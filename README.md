# Classroom Floor Planner

An interactive web-based classroom floor plan editor for designing and organizing classroom layouts.

## Features

- **Drag and Drop Interface**: Easily position furniture and fixtures
- **Furniture Items**: Beds, shelves, tables, arc tables, doors, and windows
- **Customization**:
  - Rotate items 90°
  - Resize furniture
  - Change colors with preset or custom color picker
  - Rename items with custom labels
- **Grid & Rulers**: Toggle grid and ruler displays for precise positioning
- **Print/Export**: Print to PDF for documentation
- **Global Settings**: Quickly change colors for all items of the same type
- **Zone Labels**: Add and customize zone text labels

## Usage

Simply open `index.html` in a web browser to start using the planner.

### Controls

- **Add Items**: Click toolbar buttons to add furniture
- **Move Items**: Click and drag items to reposition
- **Edit Items**: Double-click or single-click to select, then use the context menu to:
  - Change colors
  - Rotate items
  - Rename items
  - Resize width/height
  - Delete items
- **View Options**: Toggle grid, rulers, and adjust line widths
- **Print**: Use the Print/Save PDF button to export your floor plan

## Deployment

This project is designed to be deployed on [Vercel](https://vercel.com).

### Deploy to Vercel

1. Push code to GitHub
2. Import project in Vercel
3. Deploy (no configuration needed - it's a static site)

## Technology

Built with vanilla HTML, CSS, and JavaScript. No dependencies required.
